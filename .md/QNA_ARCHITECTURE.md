## Q27. 물 얼룩 제거 시간 동안 기본 상호작용 입력을 어떻게 유지할까?

- A: 한 번 누르면 청소를 시작하고 유효 조건이 유지되는 동안 자동 진행
- B: 기본 상호작용을 누르고 있는 동안만 진행
- C: 누르는 즉시 제거하고 제거 시간은 표현에만 사용
- 권장안: B — 진행률과 실제 입력을 일치시키고 시선 이탈·도구 상실 시 안전하게 중단할 수 있다.
- 답변: B

## Q28. 소지한 물걸레 또는 수건 바구니를 어떻게 내려놓을까?

- A: 각 물건의 지정된 원래 거치 위치에만 반환
- B: 유효한 바닥이면 원하는 위치에 내려놓기
- C: 별도 보관대 어디에나 반환
- 권장안: A — 기존 key rack 규칙과 같은 고정 반환 경계를 사용해 소실과 동선 차단을 막을 수 있다.
- 답변: B. 장비류는 응시방향으로 살짝 던져서 내려놓음.

## Q29. 세탁기와 건조기의 처리를 어떻게 시작할까?

- A: 첫 수건이 투입되면 즉시 자동 시작
- B: 기계의 별도 조작부를 기본 상호작용해 시작
- C: 용량이 가득 차거나 설정된 대기시간이 지나면 자동 시작
- 권장안: B — 플레이어가 투입 수량을 결정할 수 있고 수건 이동 입력과 기계 시작 입력을 서로 다른 대상으로 명확히 구분할 수 있다.
- 답변: B

## Q30. 깨끗한 수건 또는 반환 용량이 부족한 손님의 fallback은?

- A: 설정된 시간만 기다린 뒤 수건 없이 나머지 루틴 진행
- B: 설정된 시간만 기다린 뒤 무료 퇴장 루틴으로 전환
- C: 자원이 생길 때까지 계속 대기
- 권장안: A — 손님 흐름을 영구 정지시키지 않으면서 존재하지 않는 수건을 생성하거나 소실하지 않는다.
- 답변: A, 그리고 고객 내부의 만족도 수치는 하락.

## Q31. 물건을 든 상태에서 인게임 컴퓨터 사용을 시작할 수 있을까?

- A: 빈손일 때만 컴퓨터 사용 허용
- B: 물건을 든 상태 그대로 컴퓨터 사용 허용
- C: 기존 G 드랍 transaction으로 자동 내려놓기에 성공한 경우에만 컴퓨터 사용
- 권장안: A — key/mop/basket의 소유권과 드랍 실패 transaction을 건드리지 않고, held mesh가 모니터와 커서를 가리는 문제도 피할 수 있다.
- 답변: A
